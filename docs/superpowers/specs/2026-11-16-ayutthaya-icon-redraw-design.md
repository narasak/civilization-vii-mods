# Ayutthaya: redraw the 2D icon set

Date: 2026-11-16. Owner request: "ปรับชุด icon ต่าง ๆ ให้สวยงาม", approach 1 picked ("แบบที่ 1 ครับ ทำได้เลย").

- **Intent:** the six icons were assembled from basic shapes and read as stiff. At 32 px, the map-flag
  size, the swords and the alms bowl are hard to make out. Make the set look like it belongs in the game.
- **Keep the game's conventions:** unit flags and the civ symbol stay single-colour white silhouettes,
  like the game's own. The two building icons become shaded, painted-looking medallions, closer to the
  game's own building icons.
- **Constraints:** original drawings only, generated by `ayutthaya/tools/make_icons.py` (Pillow), with
  the same file names and sizes (256x256 RGBA) so no data or modinfo changes. No Buddha images. Each icon
  must still read at 32 px.
- **Approaches:** (1, picked) redraw the whole set with curves, detail and shading; (2) fix only the
  elephant, swords and bowl. Approach 2 is less work but leaves a mismatched set.
- **Icons:**
  - civ symbol: a prang flanked by two small prangs over three waves;
  - Bang Rachan: crossed Thai daap with guard, wrapped grip and pommel;
  - Royal War Elephant: profile with a curled trunk, tusk, ear and a howdah under a tiered parasol;
  - Thammathut: alms bowl with lid, knob and stand;
  - Ubosot: tiered terracotta roof with gold trim and chofa, cream walls;
  - Prang: shaded gold corncob tower with satellite prangs.
- **Left to the builder:** exact curves and colours, judged on a contact sheet at 256, 64 and 32 px, then in game.
